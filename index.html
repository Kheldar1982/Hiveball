🏈 Hiveball

Rundenbasiertes Football-Spiel im Browser.

  • Kernspiel starten
  • Manager öffnen (Kader anlegen)
  • Neu hier? Kurze Einführung für Einsteiger
  • Ausführliche Spielanleitung (Kernspiel + Manager)

Alle Spielstände werden nur lokal in deinem Browser gespeichert (localStorage) – nichts wird an einen Server übertragen.
